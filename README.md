# Bittu Builds — Design, Web & Motion

Personal brand site of Bittu. Design, video, code and creative digital experiences.

## Live site

https://bittu_builds.github.io/bittu-builds/

Hosted free on GitHub Pages.

## Files

- `index.html` — the entire site (single-file build)
- `og-image.png` — social share preview image
- `robots.txt`, `sitemap.xml` — SEO

## How to update

Replace `index.html` in this repo (upload via GitHub web UI is fine). GitHub Pages
redeploys automatically within a minute or two.
